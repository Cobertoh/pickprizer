Update lines with one tap

First time on this iPhone? Set up the free Shortcut (2 minutes, once)
  1. Open the Shortcuts app → + → name it PickPrizer. (Already made one? Delete it and start fresh.)
  2. Add Get Contents of URL. Tap the URL and paste:
  3. Add Split Text. Set it to split by New Lines.
  4. Add Repeat with Each.
  5. Inside the repeat, add Get Contents of URL. Leave its URL as Repeat Item.
  6. Below it (still inside), add another Get Contents of URL. Tap its URL, delete what's there, and paste: Then tap Show More → Method POST → Request Body File → File: Contents of URL.
  7. Done. Come back here and tap Update lines with one tap.
